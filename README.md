## Descripción del Proyecto
Este trabajo práctico consiste en el desarrollo de un sistema de control y monitoreo de Entradas y Salidas bidireccional. Consta de una placa Arduino encargada de la adquisición de estados físicos (pulsadores) y el accionamiento de cargas (LEDs), comunicada a través de un puerto serie (USB) con una interfaz gráfica desarrollada en Processing que refleja y permite comandar dichos estados en tiempo real.
